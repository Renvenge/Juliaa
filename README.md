# Happy Birthday 💗

Uma página romântica e responsiva com uma árvore formada por corações, uma mensagem de aniversário e uma interação de arco e flecha.

## Como executar

1. Baixe ou extraia os arquivos.
2. Abra `index.html` no navegador.

Não precisa de instalação nem de servidor. A fonte do Google Fonts usa internet; se estiver offline, o site usa fontes alternativas.

## Arquivos

- `index.html` — estrutura da página.
- `style.css` — visual, responsividade e animações.
- `script.js` — geração da árvore de corações e interação da flecha.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub, por exemplo `happy-birthday`.
2. Envie os três arquivos (`index.html`, `style.css`, `script.js`) e este README.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois salve.
6. Aguarde o GitHub publicar o endereço do site na própria seção Pages.
